# Red2Blue Learning

Catálogo de temas de ciberseguridad en español: cada entrada enlaza a su artículo
en el blog.

Blog: <https://purpesec.github.io/blog/>

## About

Red2Blue Learning reúne las publicaciones del blog sobre ciberseguridad en
español y las ordena como una ruta de aprendizaje: primero redes y Linux, después
seguridad ofensiva, operaciones defensivas o análisis de malware, y finalmente
writeups que aplican esos conceptos a máquinas de práctica.

El repositorio funciona como índice. El contenido completo de cada tema vive en
el blog y los laboratorios se añaden en `labs/` dentro de su área.
