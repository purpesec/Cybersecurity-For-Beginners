# Red2Blue Learning

Catálogo de temas de ciberseguridad en español: cada entrada enlaza al artículo
publicado en el blog.

Blog: <https://purpesec.github.io/blog/>

## About

Red2Blue Learning reúne mis publicaciones sobre ciberseguridad en español,
organizadas para empezar por redes y Linux y continuar con seguridad ofensiva,
operaciones defensivas o análisis de malware.

Los temas incluyen enumeración para escalada de privilegios, monitorización con
Wazuh y preparación de un laboratorio de análisis con FLARE-VM. También hay
writeups que muestran cómo aplicar los conceptos al resolver máquinas de práctica.
