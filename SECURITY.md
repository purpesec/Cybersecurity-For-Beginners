# Seguridad

Este repositorio es un catálogo de temas de ciberseguridad. Los laboratorios
incluyen código y configuraciones vulnerables de forma intencional para fines
educativos.

## Qué reportar

Se reporta la exposición accidental de secretos, dependencias comprometidas,
archivos maliciosos no simulados o cualquier riesgo que afecte a quienes clonan
el repositorio.

No se reporta como vulnerabilidad el comportamiento inseguro que un laboratorio
identifica expresamente como parte del ejercicio.

## Cómo reportar

No se publican secretos ni muestras peligrosas en un issue. Se utiliza el canal
privado de reporte de seguridad del proveedor donde esté alojado el repositorio.
Si no está disponible, se contacta de forma privada con el responsable del
repositorio.

Se incluye el archivo afectado, el impacto, los pasos de reproducción seguros y
una propuesta de mitigación cuando sea posible.
