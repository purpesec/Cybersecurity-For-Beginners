# Requisitos previos

[Inicio](../README.md) · [Catálogo](../README.md#catálogo) · [Laboratorio](../setup/README.md)

Este bloque reúne los conceptos que un alumno debe reconocer antes de empezar cualquiera de las rutas. Su referencia es el [roadmap de ciberseguridad de roadmap.sh](https://roadmap.sh/cyber-security): cubrimos sus 289 conceptos, agrupados en 16 módulos legibles y explicados con fuentes oficiales.

No es un curso ni una certificación. Es un **lector de prerrequisitos**: se consulta antes o durante una sesión cuando aparece un término que no se domina.

## Cómo usarlo

1. Identifica la ruta que vas a estudiar en la tabla de relación con las rutas.
2. Lee los módulos asociados, en orden.
3. Si un concepto aparece en una sesión y no lo entiendes, vuelve a su ancla.
4. Contrasta con las fuentes oficiales enlazadas al final de cada concepto.
5. Marca los que ya dominas: el objetivo es reconocer, no memorizar.

## Formato de cada concepto

Cada entrada incluye una definición operativa, entre cuatro y seis ideas clave, su aplicación en el repositorio y tres fuentes oficiales. El objetivo es que el alumno pueda explicar el concepto con sus palabras y sepa dónde ampliarlo.

## Criterio de fuentes

Se priorizan organismos y documentación primaria: IETF (RFC), NIST, OWASP, IEEE, ISO, Microsoft Learn, Apple, Cisco, Wi-Fi Alliance, Bluetooth SIG, IANA y documentación oficial de cada herramienta. No se enlazan blogs ni academias.
